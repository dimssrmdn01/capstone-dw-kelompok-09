## Persiapan Tahap 5: Skema SQL Silver (`src/gold/muat_silver_sql.py`)
- **Basis data pilihan:** SQLite (`data/gold/silver_stage.sqlite`) dengan tabel `silver_observasi` dan kunci primer komposit `PRIMARY KEY (indikator_id, wilayah_kode, periode)` serta tipe kolom eksplisit (`TEXT`, `INTEGER`, `REAL`).
- **Alasan & perbandingan vs dokumen JSON mentah:** SQLite tidak memerlukan server terpisah, menegakkan keunikan kunci primer untuk mencegah duplikasi observasi, dan mendukung kueri relasional/agregasi secara langsung. Sebaliknya, menyimpan respons JSON mentah sebagai dokumen mempertahankan struktur bersarang yang berbeda antara API BPS dan WDI sehingga kurang efisien untuk penggabungan lintas-sumber dan validasi tipe kolom.
